# Project Navigator

Jag skulle vilja bygga en dashboard där man till vänster har en dropdown meny där man kan välja mellan olika prosjekt jag skapat i loveable. Så klickar man på en av dem så visas dem till höger och kan användas. Hur sätter jag upp detta enklast?

This project was built with [Lovable](https://lovable.dev).

**Live app**: https://weply-sales-tools.lovable.app
